1. Requisitos

Para executar o projeto, é necessário ter acesso a uma das seguintes opções:
Google Colab: ambiente on-line para executar notebooks Python, ou o Visual Studio Code (VS Code): editor de código com Python instalado e suporte a notebooks Jupyter.
O projeto utiliza Python e a biblioteca Pandas e Numpy para importar, tratar e analisar os dados.

2. Como executar no Google Colab
Acesse o Google Colab.
Abra o notebook Miniprojeto_Analise_Varejo.ipynb, disponível neste repositório GitHub.
Se necessário, selecione a opção para abrir o notebook a partir do GitHub e informe o endereço deste repositório.
Execute as células em ordem, utilizando Ambiente de execução - Executar tudo.
Quando solicitado, carregue o arquivo Base Varejo.csv a partir do seu computador que está disponível no Kaggle no seguinte endereço: https://www.kaggle.com/datasets/namespaiva/base-varejo/data 
.
Aguarde a conclusão das etapas de importação, limpeza, validação e análise dos dados.
Ao final, verifique os resultados apresentados.

3. Como executar no Visual Studio Code
Instale o Python e o Visual Studio Code.
Baixe ou clone este repositório.
Abra a pasta do projeto no VS Code.
Instale as extensões Python e Jupyter, caso ainda não estejam instaladas.
Instale as bibliotecas necessárias em um terminal:
pip install pandas numpy
Abra o notebook Miniprojeto_Analise_Varejo.ipynb.
Selecione um ambiente Python com as bibliotecas instaladas.
Disponibilize o arquivo Base Varejo.csv no local esperado pelo código ou ajuste o caminho do arquivo, se necessário.
Execute as células em ordem e confira os resultados.

4. Resultado esperado
Ao executar o notebook, serão realizadas as seguintes atividades:
Importação e inspeção da base de dados.
Identificação e remoção de colunas totalmente vazias.
Conversão e validação dos tipos de dados.
Diagnóstico e tratamento de valores ausentes e inconsistências.
Normalização dos campos de texto.
Identificação e remoção de duplicados exatos.
Estatística descritiva da variável CL_FHL.
Análises agrupadas com groupby e pivot_table.
